# VideoFilteringCore 核心算法引擎
本模块为项目的**核心静态库（.lib）**，负责所有AI推理、语义匹配、文本处理、业务调度逻辑，与UI层完全解耦，可独立编译、复用、移植。

---

## 一、模块定位
- 纯 C++ 实现，**无任何 Qt / UI 依赖**
- 编译为静态库，提供黑盒服务
- 对外仅通过抽象接口 IApplicationController 提供服务
- 内部包含完整算法 pipeline：文本清洗 → 向量化 → 语义匹配 → 结果输出

---

## 二、目录结构与职责
### application
应用层入口与接口定义
- IApplicationController：对外抽象接口（UI 唯一调用入口）
- FilterEngine：核心调度器，管理全局状态与配置

### business_operations
业务编排层，将基础能力组装为完整业务流程

### core
算法内核层
- 语义原型向量匹配（模板内评论嵌入取均值 → 与待检评论算余弦相似度 → 阈值判定）
- 相似度计算、语义判定、阈值策略

### clean
文本清洗与数据预处理
- 评论解析、噪声过滤、格式标准化

### model
AI 模型与向量化
- MiniLM 模型加载
- 文本向量生成
- 语义库管理

### onnx / sentencepiece
AI 推理底层支持
- ONNX 运行时封装
- 分词与文本预处理算子

### utils
通用工具集
- 文件、字符串、数学、日志、系统工具

### framework
平台宏定义、编译配置

---

## 三、外部依赖（静态库链接）
本模块依赖以下第三方静态库：
- ONNXRuntime：AI 模型离线推理
- SentencePiece：文本分词与预处理
- nlohmann_json：配置与数据解析

所有依赖均为标准静态链接，不影响模块化与独立性。

---

## 四、设计规范
1. 单向依赖：UI → 接口 → Core，禁止反向调用
2. 接口隔离：UI 仅可见抽象接口，不可见内部实现
3. 无UI侵入：Core 不使用任何 Qt/窗口/控件代码
4. 高内聚低耦合：模块职责清晰，无循环依赖
5. 可复用性：可直接移植到其他项目作为语义引擎使用

---

## 五、对外接口
UI 层通过 IApplicationController 访问所有功能：
- 初始化引擎
- 加载评论数据
- 启动语义筛选
- 设置匹配阈值
- 获取筛选结果
