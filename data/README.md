# data/ 目录说明

本目录存放程序运行期的配置与语义模板数据。

## 随仓库分发的文件

| 路径 | 说明 |
|---|---|
| `config.json` | 筛选参数配置，程序启动时读取，修改参数后自动回写 |
| `positive_templates/*.json` | 正向语义模板（示例，可自行增删） |
| `negative_templates/*.json` | 负向语义模板（示例，可自行增删） |

### config.json 字段

```json
{
    "mode": 3,                  // 运行模式位掩码：1=正向 2=负向 3=双向
    "positive_threshold": 0.5,  // 正向命中阈值（余弦相似度）
    "negative_threshold": 0.5,  // 负向命中阈值
    "record_data": true         // 是否记录运行数据
}
```

### 模板文件格式

每个 `.json` 是一个语义模板分组，内含一组示例评论。程序会把这组示例评论分别编码后取**均值**，得到一个"语义原型向量"，再与待检测评论做余弦相似度比较——即多实例学习（MIL）的思路。

程序只加载本层目录下的 `*.json` / `*.JSON`，不递归子目录。

## 运行期自动生成（不纳入版本控制）

| 路径 | 说明 |
|---|---|
| `raw/` | 抓取到的原始评论 |
| `cleaned/` | 清洗后的评论 |
| `parser/` | 窗口绑定的解析配置 |
| `SimilarityCheck/` | 相似度判定结果快照 |

这些目录由程序运行时创建，已在 `.gitignore` 中排除。
